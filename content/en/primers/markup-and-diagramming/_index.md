These primers teach writing and visualization as part of development workflow, enabling developers to communicate clearly and consistently.

## Planned Primers

### Text Markup
- Markdown — Lightweight formatting for documentation
- AsciiDoc — Feature-rich technical writing
- reStructuredText — Python documentation standard
- LaTeX — Professional typesetting for technical documents

### Data Markup
- YAML — Human-readable data serialization
- JSON — Structured data interchange
- TOML — Configuration files with clarity

### Diagramming
- PlantUML — Text-based UML diagrams
- Mermaid — Diagrams in Markdown
- Graphviz DOT — Graph visualization language
- D2 — Modern declarative diagramming

### Visual Data
- Vega-Lite — Declarative visualization grammar
- SVG fundamentals — Scalable vector graphics
