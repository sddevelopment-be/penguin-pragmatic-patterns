A collection of concise, pattern-informed guides for experienced developers learning new languages. Each primer moves beyond syntax to explore the philosophy, idioms, and ecosystem tooling that define real fluency.

## Available Primers

- [Python](python) — Clarity over cleverness; readability as a social contract
- [Perl](perl) — Expressive power and practical text processing

## Planned Primers

- Rust — Memory safety without garbage collection
- Go — Simplicity and concurrency for networked systems
- Kotlin — Pragmatic JVM language with modern features
- Java — Enterprise-grade object-oriented programming
- C# — .NET ecosystem and cross-platform development
- JavaScript/TypeScript — Web and server-side scripting with type safety
- Lisp — Code as data, meta-programming fundamentals
- Prolog — Logic programming and declarative problem-solving
- Haskell — Pure functional programming with strong types
- C — Low-level systems programming
- Eiffel — Design by contract principles
- Smalltalk — Object-oriented messaging paradigm
- Groovy — Dynamic JVM scripting
