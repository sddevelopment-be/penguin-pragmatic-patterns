# Penguin Pragmatic Patterns — Agent Notes

> Keep these references handy while working in this repository. They capture structure, editorial rules, and recently touched artefacts.

## Project Topology

- `content/` Hugo Markdown source per locale (default: `content/en`); practice template lives at `content/en/practices/TEMPLATE_PRACTICE.md`.
- `layouts/`, `archetypes/`, `assets/`, `static/`, `resources/` provide theming, shortcodes, assets, and generated resources. `public/` is build output.
- `data/` stores TOML datasets (glossary, bibliography, etc.); `config.yaml`, `crowdin.yml`, `netlify.toml` configure site, localization, deployment.
- `src/` and `code/` hold supporting scripts/components; `auto/` captures automation metadata.
- `tmp/` contains drafts (ignored by git). Promote into `content/` for publication-ready work.

## Authoring Rules

- Work on English content unless NL updates are explicitly requested.
- Practice `categories` must be one of `learning`, `productivity`, `communication`, `software development`.
- Every tag must exist in the locale’s `data/glossary.toml`. When adding a new tag, create/propose the glossary entry alongside the content.
- Use Hugo-style front matter (`+++`) with `uuid`, `aliases`, `outputs`, and AMMERSE deltas.
- GPG signing is blocked in this environment; commits require `--no-gpg-sign`.
