# Work Logs

This repository stores doctrine-aligned work logs here.

## Locations

- Agent execution logs: `work/reports/logs/<agent-slug>/`
- Prompt analysis logs (Directive 015): `work/reports/logs/prompts/`

## Naming

- Work logs: `YYYY-MM-DDTHHMM-<description>.md`
- Prompt logs: `YYYY-MM-DDTHHMM-<agent>-<slug>-prompt.md`
