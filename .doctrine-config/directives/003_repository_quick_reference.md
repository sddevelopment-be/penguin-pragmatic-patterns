# 003 Repository Quick Reference (Local Override)

Source: migrated from legacy `.github/agents/directives/003_repository_quick_reference.md` on 2026-02-12.

Key directories:

- `content/`, `layouts/`, `static/` - Hugo site structure
- Build/config: `config.yaml`, `data/`, `resources/`, `netlify.toml`
- Tooling/source: `src/`, `assets/`
- Dependencies: `package.json`, `go.mod`
- Generated (do not edit): `public/`, `.hugo_build.lock`
- Templates: `docs/templates/`

Version requirement:

- Hugo `0.152.2` extended (SCSS support)
