# Contextive Glossary Files

This directory contains Contextive-compatible glossary files that enable IDE integration for ubiquitous language terms used across the Penguin Pragmatic Patterns knowledge base.

## What is Contextive?

[Contextive](https://github.com/dev-cycles/contextive) is a suite of tools that immerse developers in the language of their users' domains. It provides:

- **Hover definitions**: See term definitions when hovering over words in code, comments, or documentation
- **Auto-complete**: Get term suggestions as you type
- **Ubiquitous language management**: Maintain consistent terminology across your codebase

## File Structure

This directory contains one YAML file per domain, following the pattern `<domain>.glossary.yml`:

- `software.glossary.yml` - Software development terms (66 terms)
- `communication.glossary.yml` - Communication and collaboration terms (7 terms)
- `productivity.glossary.yml` - Productivity and task management terms (8 terms)
- `psychology.glossary.yml` - Psychology and behavioral terms (5 terms)
- And 50+ other domain-specific files...

Each file includes:
- **Domain vision statement**: High-level description of the domain's purpose
- **Metadata**: Ownership and maintenance information
- **Terms**: Individual glossary entries with definitions, aliases, and usage examples

## How to Use

### IDE Setup

1. **Install Contextive** for your IDE:
   - [VS Code Extension](https://marketplace.visualstudio.com/items?itemName=devcycles.contextive)
   - [IntelliJ Plugin](https://plugins.jetbrains.com/plugin/18869-contextive)
   - [Visual Studio Extension](https://marketplace.visualstudio.com/items?itemName=devcycles.contextive-vs)
   - Or any IDE supporting Language Server Protocol

2. **Configure Contextive** to use this directory:
   - Contextive will automatically detect `.contextive/*.yml` files in the repository root
   - No additional configuration needed!

3. **Use the glossary**:
   - Hover over terms in your code or documentation to see definitions
   - Type terms to get auto-complete suggestions
   - Browse the glossary in your IDE's Contextive panel

### Regenerating the Files

These files are auto-generated from `data/glossary.toml`. To regenerate after updating the source:

```bash
python3 src/scripts/ops/generate_contextive_glossary.py
```

The script will:
- Read all terminology from `data/glossary.toml`
- Group terms by domain
- Generate one YAML file per domain
- Include domain vision statements and metadata
- Convert references to usage examples

## File Format

Each glossary file follows the Contextive YAML schema:

```yaml
contexts:
  - name: Domain Name
    domainVisionStatement: Description of the domain's purpose
    meta:
      "👥 Owner": Team Name
    terms:
      - name: Term Name
        definition: Clear explanation of the term
        aliases:
          - Alternative Name
          - Abbreviation
        examples:
          - Usage example or reference link
```
