Execution Flow
==============

Start
  │
  ├─► Step 1: Run lint service
  │     │
  │     ├─ lint:css (stylelint)
  │     ├─ lint:js (eslint)
  │     ├─ lint:md (remark)
  │     └─ Result: reports/npm-lint-latest.log
  │
  ├─► Step 2: Run hugo-test service
  │     │
  │     ├─ Build site (--gc --minify --panicOnWarning)
  │     ├─ Check internal links
  │     ├─ Check external links
  │     └─ Result: Exit code 0 if successful
  │
  ├─► Step 3: Start hugo-server service (background)
  │     │
  │     ├─ Bind to 0.0.0.0:1313
  │     ├─ Wait for health check (curl)
  │     └─ Keep running for dependent services
  │
  ├─► Step 4: Run smoke service
  │     │
  │     ├─ Wait for hugo-server health
  │     ├─ Run Cypress E2E tests
  │     │   ├─ Main page loads
  │     │   ├─ Navigation works
  │     │   ├─ Footer present
  │     │   └─ Links functional
  │     └─ Result: cypress/videos/, cypress/screenshots/
  │
  └─► Step 5: Run lighthouse service
        │
        ├─ Wait for hugo-server health
        ├─ Audit performance
        ├─ Measure Core Web Vitals
        └─ Result: reports/lighthouse-desktop.report.{html,json}

GitHub Actions Parity
======================

GitHub Actions Workflow          Docker Compose Service
────────────────────────────────────────────────────────
Job: lint                     →  Service: lint
  - npm run lint:css               - npm run lint:css
  - npm run lint:js                - npm run lint:js
  - npm run lint:md                - npm run lint:md

Job: hugo-test                →  Service: hugo-test
  - hugo --gc --minify             - hugo --gc --minify
  - hugo check --links             - hugo check --links

Job: smoke                    →  Service: smoke + hugo-server
  - Start hugo server              - docker-compose up hugo-server
  - npx wait-on                    - npx wait-on
  - npm run test:cypress           - npm run test:cypress

Environment:                     Environment:
  - Hugo: 0.152.2                  - Hugo: 0.152.2 ✓
  - Node: 25.1.0                   - Node: 25.1.0 ✓
  - Ubuntu: latest                 - Ubuntu: 24.04 ✓


Usage Examples
==============

# Run everything
bash scripts/run-validation-docker.sh

# Individual services
docker-compose -f docker-compose.validation.yml run --rm lint
docker-compose -f docker-compose.validation.yml run --rm hugo-test

# Development server
docker-compose -f docker-compose.validation.yml up hugo-server
# Access at http://localhost:1313

# Full smoke test suite
docker-compose -f docker-compose.validation.yml up -d hugo-server
docker-compose -f docker-compose.validation.yml run --rm smoke
docker-compose -f docker-compose.validation.yml run --rm lighthouse
docker-compose -f docker-compose.validation.yml down

# Cleanup
docker-compose -f docker-compose.validation.yml down -v
docker system prune
